# SOAP帳票の表示・印刷テンプレート

「04 表示・印刷テンプレート」のプルダウンで3種類を選択できます。
SOAP生成前は内容の位置を示す見本、生成後は編集済みのSOAP本文を表示します。
表示形式を変えるだけなので、切り替えでAI APIを再実行しません。

| テンプレート | 表示 |
|---|---|
| 標準SOAP | S/O/A/Pと要確認欄を縦に配置 |
| 表形式 | SOAP区分と本文を2列の表で表示 |
| 診療記録票 | 患者ID・診察日時・担当医・施設名の任意欄とSOAP本文 |

## 操作

1. 文字起こしと話者を確認し、従来どおりSOAP下書きを生成する。
2. 「03 SOAP下書きを編集・確認」の各欄を編集する。プレビューも更新される。
3. テンプレートを選ぶ。「診療記録票」の基本情報は手入力する。空欄は空欄のまま。
4. 医師が本文・分類・基本情報を確認し、医師確認チェックを入れる。
5. 「選択した形式で印刷 / PDF保存」で別画面を開き、そこで「印刷 / PDF保存」を押す。
   ブラウザの印刷先でプリンター、またはPDF保存を選択する。

A4縦、余白16mmの印刷CSSを指定しています。ブラウザの印刷ダイアログでもA4を選択し、
必要に応じてブラウザ側のヘッダー・フッター（URLなど）を無効にしてください。
長文はページをまたぎます。文字数を理由に本文や要確認欄を切り捨てません。
改ページ位置・フォント・印刷設定はブラウザやプリンターでも変わります。

本文・基本情報を変えると医師確認が解除されます。形式変更だけでは解除しません。
コピーはテキスト形式で、診療記録票を選んでいる場合は基本情報も含みます。
印刷画面は開いた時点のスナップショットです。後で編集した場合は閉じて開き直してください。

## データ

基本情報はAIへ送信せず、この画面内のメモリだけで扱います。DB・localStorageへの保存は
追加していません。全消去・ログアウト・ページ再読み込みで基本情報も消去します。
別の録音・音声ファイル・架空会話に切り替える場合も、前の基本情報を消去します。
患者氏名の入力欄は設けず、必要最小限の患者IDで運用してください。
コピー先、PDF、すでに開いた印刷画面の情報は元画面を消去しても残るため、手元で管理します。

## EC2への反映

この変更は静的HTML/CSS/JavaScriptと配置スクリプトのみです。Docker再ビルドは不要です。
PRをmainへマージした後、EC2のチェックアウトで実行します。

```bash
cd ~/soap-note-assistant
git switch main
git pull --ff-only origin main
sudo sh scripts/install-static.sh
```

実際のEC2側チェックアウトが別の場所なら、そこへ移動してください。
ホストのsudo権限を持つEC2管理者が配置します（deepstationのsudoは不要）。
Apache設定の変更・再起動は不要。ブラウザでSOAP画面を再読み込みしてください。
配置スクリプトは新しい `report.js` もコピーします。古いスクリプトでの手動配置は避けます。
